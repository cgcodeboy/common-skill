# 教案内容（与载体无关）

载体选型与目录见 [formats.md](formats.md)。难度与课型见 [intake.md](intake.md)。本节规定**教什么**：不论 markdown、ppt 还是 html，缺了这些就不合格。

## 课次数量（随难度）

| 难度 | 课次数 | 坡度要求 |
| --- | --- | --- |
| 简单 | **3–4** | 问题与直觉 + 最小词汇/总图 + 一个轻案例；不到机制深水 |
| 中等 | **5–8** | 完整四阶段（见下表）；默认档 |
| 复杂 | **8–12**，或 5–8 主干 + 标注的前沿专次 | 四阶段齐全，另有争议/前沿/证伪 |

更多要有极强理由并在清单写明。每课应能在一次教练对话里讲完主干（约 25–45 分钟等效；简单档可更短）。

## 由浅入深

| 阶段 | 课次位置 | 必须出现 | 简单档 |
| --- | --- | --- | --- |
| 问题与直觉 | 前 1–2 课 | 为什么学、现实问题、最小心智模型 | 必有 |
| 核心模型 | 中间 | 主概念、关系/结构、可跟随的小案例 | 压缩为 1 课 |
| 机制与取舍 | 中后 | 失败模式、两种真实做法对比、依据来源 | 可改为「常见坑」半课 |
| 综合 | 末 1–2 课 | 带从业约束的端到端案例、自检与复习 | 轻量走查即可 |
| 前沿（仅复杂或前沿实例=开） | 靠后 | 近沿实例、开放问题、如何跟踪 | 简单档默认无 |

## 每课必备槽位

不论落在哪种载体上，每课都要能指认出（再按课型加减）：

1. **目标**（可检验）  
2. **讲解顺序 / beat 列表**（lecture=开时必须完整；关时至少极简导读）。写成可打断回点的节拍，供 `/polymath coach` 使用，例如：  
   `B1` 一句话目标 → `B2` 概念 → `B3` 打开 lab 并观察… → `B4` 互动题。  
   全局 id 建议 `L0N-B*`。详见 [live-teaching.md](live-teaching.md)。  

3. **图**（至少一幅；简单档允许全课共用总图但每课要引用）  
4. **案例**（角色、约束、步骤、取舍/翻车）  
5. **互动提问**（2–4，暴露误解；练习=关时可减为 1 道口头题）  
6. **常见误区**  
7. **自检**（练习=开：2–3 题；关：可 0–1，须在清单写明）  
8. **本课依据**（来源 URL 或仓库路径）  
9. **前沿切片**（仅该课标注为前沿实例时：论文/仓库/系统入口 + 要观察的结论）

## 案例标准

1. **角色**：谁在什么系统里遇到问题  
2. **约束**：流量、一致性、成本、兼容、团队规模等至少一条  
3. **步骤**：具体到命令、配置键、代码位置或页面操作级别  
4. **取舍或翻车**：做好看见什么；做错常见症状  

禁止：无约束 Hello World；与本课目标无关的大而全 Demo。

```markdown
- 学习目标：
- 难度：简单 | 中等 | 复杂
- 课型组件：lecture=；练习=；前沿实例=
- 难度与广度说明：
- 建议总课时：
- 已选载体：
- 配套教练命令：`/polymath coach`
- 清单：<父目录>/<slug>-polymath/清单.md

## 来源摘要
## 课次地图
## 课次 1：…
### 目标
### 讲解顺序
### 图
### 案例
### 互动提问
### 常见误区
### 自检
### 本课依据
### 关联 ppt / html
（页范围或 labs 路径）
```

## ppt / html

页类与实例要求见 [formats.md](formats.md)。内容槽位与上表一一对应：扉页←目标，概念/图示←讲解与图，案例页←案例，互动/自检页←提问与自检。

## 合格线

- [ ] 父目录与 `<slug>-polymath` 已确认；目录名带统一后缀  
- [ ] 难度与课型组件已确认并写入清单；课次数与深度匹配该档  
- [ ] 已选载体，且 `清单.md` 写清路径  
- [ ] 元信息目标可检验；来源满足 research.md 最少合格集（含前沿实例开启时的加码）  
- [ ] 课次地图有深浅坡度（简单档允许短坡，不得伪造成中等）  
- [ ] 每课必备槽位按课型裁剪后仍齐全（可分布在不同载体）  
- [ ] lecture=开 → 讲解顺序可讲完；练习=开 → 关键课有可做练习；前沿实例=开 → 有带 URL 的前沿课次  
- [ ] 声明了 markdown → 有完整 `教案.md`  
- [ ] 声明了 ppt → 有可打开的 `.pptx`（或清单写明的可一键导出产物，且源码齐全）  
- [ ] 声明了 html → 每相关课次有可打开的 `index.html` 实例，不是空壳  
- [ ] 中等/复杂的综合阶段有贴近实际的约束
