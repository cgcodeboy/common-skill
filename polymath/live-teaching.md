# 真人语音课与 Agent 衔接

人工语音教学、随时打断、复杂课内环境：**主循环是当前对话里的 `/polymath coach`（文字或 Cursor 语音）**，不是 `index.html`。

## 角色分工

| 角色 | 职责 | 不负责 |
| --- | --- | --- |
| **`/polymath coach`（本对话 agent）** | 出声/打字讲解；听打断；按教案 beat 前进/回退/跳转；决定何时打开 lab；读写进度 | 在 HTML 里跑独立 TTS 教案 |
| **`教案.md`** | 剧本与 beat 列表（可讲、可问、可挂 lab） | 运行时状态 |
| **`进度.md`（+ 可选 `状态.json`）** | 当前课次、beat、卡壳、下次从哪续 | 替代对话里的即时打断处理 |
| **`labs/**/index.html`** | 图、模拟、跟练台（教具） | 语音主循环、打断路由、当课包大脑 |
| **`slides/*.pptx`** | 可选放映 | 控场与答疑 |
| **可选 `副屏/index.html`** | 只读展示当前 beat 提词/题目（由 coach 口述「请看副屏」） | 点下一页驱动整门课；页内 TTS 教完全课 |

## 控制链

```text
学员（语音或文字，可随时打断）
    → 本对话 /polymath coach
    → 读 清单 + 教案当前课 beat + 进度.md
    → 决定：续讲 | 追问 | 回退 beat | 打开 lab | 跳课 | 自检
    → 需要教具时：给出 lab 路径（或用浏览器打开），说明看哪里、点什么
    → 段末或打断处理后：更新 进度.md
```

## Beat（最小授课单位）

教案每课的「讲解顺序」拆成带 id 的节拍，便于打断后回点。写法见 [curriculum.md](curriculum.md)。

coach 每次只推进 **一个或少数 beat**，然后停顿等学员；禁止一次倾倒整课。

打断例句与处理：

| 学员 | coach |
| --- | --- |
| 「等下，上一个再讲讲」 | 回退到上一 beat 或点名的概念 beat |
| 「这个 lab 怎么点」 | 暂停讲稿，打开/指引当前课 lab，不换课 |
| 「先跳到综合」 | 标明缺的先修，记进度「跳过」，再开目标课 |
| 「我懂了继续」 | 从进度中的下一 beat 续 |

## 语音怎么和内容衔接

1. **声源**：Cursor 语音通话或聊天里的 coach 回复 = 讲解声。  
2. **词源**：当前 beat 的提词来自 `教案.md`，不是 HTML 内嵌另一份讲稿。  
3. **视源**：说到「看图/做练习」时，才拉起 lab 或 ppt；用一句话对齐（「看课次 03 页面上的 CFL 数字」）。  
4. **禁止**：在 lab/`副屏` 里用 TTS 自动念完整讲稿并当作主课；禁止 HTML `localStorage` 当作与 agent 脱节的唯一进度。

## 进度文件（coach 应维护）

路径：`<课程包>/进度.md`。复杂打断频繁时，可另写 `<课程包>/状态.json` 便于机器读，字段与进度一致。

```markdown
# 进度

- 课程包：
- 难度 / 课型：（从清单抄）
- 已完成课次：
- 进行中课次：
- 当前 beat：L03-B2
- 卡壳：
- 打开中的教具：（lab 路径或无）
- 下次：续 L03-B3 / 或课次 4
```

```json
{
  "course": "cfd-polymath",
  "lesson": 3,
  "beat": "L03-B2",
  "lab": "labs/课次-03/index.html",
  "note": ""
}
```

## 与 syllabus 的关系

syllabus 交付能被 coach 按 beat 执行的剧本和教具。不交付「可离线自动讲完」的语音站点。lecture=开 → 教案含 beat；练习=开 → lab 挂到对应 beat；不是 lab 取代 coach。
