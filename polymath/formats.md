# 教案载体

内容要求（目标、坡度、图、案例、互动、自检、来源）对所有载体相同。载体只决定怎么呈现和打开。用户指定一种或多种；未指定时先问，默认 **markdown + 关键课次的 html 实例**（图多、要演示时再加 ppt）。

课程包落盘与命名先读 [workspace.md](workspace.md)。目录必须是 `<父目录>/<slug>-polymath/`。

## 目录约定

```text
<父目录>/<slug>-polymath/
  清单.md                 # 必交：载体、路径、课次地图、难度与课型
  来源.md                 # 建议
  教案.md                 # 剧本 + beat；语音课词源
  slides/                 # 可选放映
  labs/
    课次-01/
      index.html          # 教具：图/模拟/跟练；禁止当语音主课
  副屏/index.html         # 可选：只读提词副屏，由 coach 驱动看哪一拍
  进度.md                 # coach 维护：课次/beat/卡壳
  状态.json               # 建议：机读进度，与进度.md 一致
```

`清单.md` + 本对话 `/polymath coach` 是授课入口。没有清单，只有散文件，不算交付完成。

**html 定位**：卫星教具。由 coach 在对应 beat 打开并口头对齐；不得在页内用 TTS/自动播放替代 agent 讲解与打断处理。衔接约定见 [live-teaching.md](live-teaching.md)。

## markdown

适合：完整剧本、长案例步骤、自检参考、给教练逐段讲。

路径：`教案.md`。章节骨架见 [curriculum.md](curriculum.md) 的「markdown 骨架」。必须能被 `/polymath coach` 按课次定位。

图：Mermaid 或引用 `labs/` 里的截图/页面。

## ppt

适合：课堂放映、一页一意、图示与关键词、口头展开的提纲。

交付 **可打开的 `.pptx` 文件**，不是聊天里的「第 N 页：标题」列表冒充 PPT。

生成方式（按可用性选一种，并在清单写明）：

1. **优先**：`python-pptx` 脚本写出 `.pptx`（标题、要点、示意图占位说明、案例页、互动页、自检页）。
2. **备选**：Marp / Reveal 源文件 + 导出说明；若环境能导出 pptx/pdf 则导出，否则至少留下可 `npx`/`marp` 一键生成的源，并在清单标明「源 → 命令 → 产物」。

页结构（每课一组，全课可合并为一个文件）：

| 页类 | 必须 |
| --- | --- |
| 课次扉页 | 标题、本课目标（1–3 条） |
| 概念页 | 少字，一页一意 |
| 图示页 | 结构/流程；复杂图可写「见 html 实例」 |
| 案例页 | 角色、约束、步骤要点、取舍 |
| 互动页 | 提问（不要印答案） |
| 自检页 | 题目（答案放讲师备注或 markdown，不印在学员页） |

禁止：把整课讲稿糊进一页；无图无案例的纯目录 PPT。

## html

适合：可点击的教学实例、迷你演示、对照好坏配置、跟练台。浏览器直接打开 `labs/课次-0N/index.html`。

每课至少一个实例目录（综合课可多个）。页面须：

1. 写清本课目标与「你在这个实例里要观察/操作什么」  
2. 有可见的结构或交互（图解、分步、对照、简易模拟均可）  
3. 案例约束写在页上，不是只有装饰性动画  
4. 假数据或内存逻辑即可；能说明真实取舍  
5. 不依赖外网 CDN 才能看懂主干（可选增强允许联网）  
6. 可接受 `?beat=L0N-B*` 高亮，但**权威进度仍在** `进度.md` / coach 对话

禁止：空白壳页面；只有外链列表；线框占位冒充实例；页内 TTS 自动讲完整课；在 HTML 里实现与 agent 无关的「整门课播放器」。

## 副屏（可选）

`副屏/index.html`：大字提词 + 当前题，供老师/学员另屏看。内容由教案 beat 生成或由 coach 指定；点击「下一拍」若存在，只作建议，**是否换拍以对话里 coach 为准**。

## 多载体同时交付

同一门课可同时有 markdown（剧本）+ ppt（放映）+ html（实例）。三者课次编号必须一致。内容冲突时以清单课次地图为准，改完同步三处或在清单写明「以哪份为准」。

## 教练怎么读

`/polymath coach` 先读 `清单.md` 与 `进度.md`，按 beat 讲解；需要时再打开 ppt/lab/副屏。详见 [live-teaching.md](live-teaching.md) 与 [session.md](session.md)。
