# 课程包落盘（先于取材与写作）

`/polymath syllabus` 与 `/polymath coach` 共用本约定。

未确认**父目录**与**课程包目录名**之前，不准创建文件、不准开始大段取材写作。

## 统一后缀

所有课程包目录名必须以 **`-polymath`** 结尾。

```text
<父目录>/<slug>-polymath/
```

| 部分 | 规则 |
| --- | --- |
| 父目录 | 用户确认的绝对或相对路径；默认提议当前工作区根下的 `docs/courses`（若用户只要仓库根或别的路径，以确认结果为准） |
| slug | 由领域压缩：小写英文字母、数字、连字符；短、稳定、可读；不用中文、空格、下划线 |
| 后缀 | 固定 `-polymath`，不可省略、不可改成 `-course` / `-edu` 等 |

示例：

| 用户说法 | 提议目录名 |
| --- | --- |
| CFD / 计算流体力学 | `cfd-polymath` |
| WebRTC | `webrtc-polymath` |
| 系统仿真且主攻 CFD | `cfd-polymath`（主领域作 slug；仿真外沿写进清单目标，不把目录拉成一长串） |

已存在同名 `-polymath` 目录且含 `清单.md` → 先读再问：续写、覆盖课次，还是换 slug（如 `cfd-advanced-polymath`）。

## 开场必问（可合并一轮，下列必须确认或复述确认）

1. **父目录**：课程包放在哪？（给出默认提议 + 当前工作区路径）  
2. **目录名**：根据领域提议 `<slug>-polymath`，请用户确认或改 slug  
3. **难度**：简单 / 中等 / 复杂 —— 细则与场景见 [intake.md](intake.md)  
4. **课型组件**（可多选，逐项开/关）：**lecture**、**练习**、**前沿实例** —— 默认随难度，见 intake  
5. 其余：先验、目标、载体（见 [syllabus.md](syllabus.md)）

用户改了 slug 时，仍必须保留 `-polymath` 后缀。用户坚持不要该后缀 → 说明本技能约定不可破，请改用别的流程；不要擅自建无后缀目录。

未确认难度与课型组件之前，不准定课次地图、不准按某一档硬写教案。

## 确认后

```bash
mkdir -p "<父目录>/<slug>-polymath"
```

清单与所有制品只写在该目录内。清单里写清：

- 父目录  
- 课程包路径（含 `-polymath`）  
- slug  
- 难度  
- 课型组件：lecture / 练习 / 前沿实例  


## coach 查找顺序

1. 用户给出的路径 → 落到课程包根，校验 `-polymath` 后缀。  
2. 只给领域 → 在已确认父目录下找 `<slug>-polymath/清单.md`，或列出所有 `*-polymath` 供选。  
3. 父目录未确认 → 先问父目录。  
4. 无清单 → 不开讲，引导 `/polymath syllabus`（不要为开讲擅自建包塞临时大纲）。

## 禁止

- 未确认父目录就在随意路径落盘  
- 目录名无 `-polymath` 后缀  
- 用中文或空格当目录名  
- 把多门课塞进同一个 `-polymath` 目录却不改清单（一门课一个包）
