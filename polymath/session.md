# 授课节奏（Agent 主循环）

先读 [live-teaching.md](live-teaching.md)。

## 开场检查

1. 读 [workspace.md](workspace.md)。未给路径则先确认父目录，再找 `*-polymath`。  
2. 读 `清单.md`：难度、课型、载体、课次地图。  
3. 读 `进度.md` / `状态.json`（若有）：课次、beat、卡壳、打开中的教具。  
4. 打开本课将用到的教案章节；**先不要**自动念整课或自动开所有 lab。  
5. 五行内说清：课程包、难度、课型、进行中课次/beat、是否续讲。  
6. 若学员要语音课：确认 Cursor 语音通话已接通；未接通则先请打开 Voice，再开讲。  
7. 问：从哪一课、哪个 beat 开始？（默认进度中的「下次」，否则课次 1 的 B1）

没有清单 → 停止，示例须含难度与课型，见下：

```text
/polymath syllabus
我想学 <领域>，先验是…，目标是…。
难度：简单 / 中等 / 复杂
课型：lecture=开；练习=…；前沿实例=…
课程包父目录：<路径>
目录名：<slug>-polymath
载体：markdown + html（或 ppt / 组合）。先出教案。
```

## 单课循环（可被随时打断）

1. 宣告：**课次 N · beat id · 一句话目标**。  
2. **讲**：按该 beat 提词讲完最小块（lecture=开）。  
3. **教具**（若该 beat 挂了 lab/ppt）：给出路径或打开浏览器，说明观察点/点击；不把页面当主讲人。  
4. **停**：抛一个检查点或等学员；练习=开则用教案互动题。  
5. 学员若打断 → 走「打断处理」，不要无视插话继续念下一页。  
6. 本 beat 达成 → 写进度 → 下一 beat；课次结束再问是否下一课。

## 打断处理

| 信号 | 动作 |
| --- | --- |
| 追问当前概念 | 停在本 beat 加深；可回指图/lab |
| 「上一句/上一段」 | 回退 1 个 beat |
| 「打开练习」 | 打开本课 lab，暂停讲稿推进 |
| 「跳到第 K 课」 | 提示先修缺口；进度记跳过；再开 K |
| 「先讲完再问」 | 本课 beat 可连讲，但课末仍须互动（练习=开时） |
| 「够了/休息」 | 立刻写进度并停 |

## 答错

指到卡在哪个 beat；回退到图或 lab；变体题；仍错则不要强行下一课次。

```markdown

- 课程包：<父目录>/<slug>-polymath
- 难度 / 课型：
- 已完成课次：
- 进行中课次：
- 当前 beat：
- 卡壳：
- 打开中的教具：
- 下次：
```

**`状态.json`（建议）**

```json
{
  "lesson": 1,
  "beat": "L01-B1",
  "lab": null,
  "note": ""
}
```

HTML lab 内不要另搞一套与上述冲突的「课程总进度」权威源。
