# common-skill

跨项目共用的 Cursor skills。每个 skill 是仓库根目录下的一个文件夹。

| 命令 | 目录 | 作用 |
| --- | --- | --- |
| `/system-interaction` | `system-interaction/` | 系统交互：把任务补成可度量场景，取舍呈现、编辑和寻找，做可走查的原型并亲自走通。安装见 `system-interaction/INSTALL.md`，用法见 `system-interaction/USAGE.md` |
| `/system-architecture` | `system-architecture/` | 系统架构：补全质量场景，在结构、通信、数据、部署上分别取舍，用视图走通场景并反思。安装见 `system-architecture/INSTALL.md`，用法见 `system-architecture/USAGE.md` |
