# common-skill

跨项目共用的 Cursor skills。每个 skill 是仓库根目录下的一个文件夹。

| 命令 | 目录 | 作用 |
| --- | --- | --- |
| `/system-interaction` | `system-interaction/` | 系统交互：参照同类系统的真实页面，交出美观、大气、简洁的 UI/UX 稿，浏览器能打开并用假数据走完主任务。安装见 `system-interaction/interaction-install.md`，用法见 `system-interaction/interaction-use.md` |
| `/system-architecture` | `system-architecture/` | 架构：交付 `docs/框架设计.md` 和按 GB/T 8567 编写的 `docs/概要设计说明书.md`。安装见 `system-architecture/architecture-install.md`，用法见 `system-architecture/architecture-use.md` |
| `/system-detail` | `system-detail/` | 详细设计：交付按 GB/T 8567 编写的 `docs/详细设计说明书.md`。安装见 `system-detail/detail-install.md`，用法见 `system-detail/detail-use.md` |
